# 参考解答

乙说真话。

形式化：用 a、b、c 分别表示甲、乙、丙说真话。一人说真话 ⇔ 其陈述为真，说谎 ⇔ 其陈述为假。

- 甲说"乙在说谎"：a 真 ⇔ b 假
- 乙说"丙在说谎"：b 真 ⇔ c 假
- 丙说"甲和乙都在说谎"：c 真 ⇔（a 假 且 b 假）

推理：由前两式，a 与 b 一真一假，b 与 c 一真一假，因此 a = c 且 b 与 a 相反。

- 若 a 真（甲说真话）：则 b 假、c 真。c 真要求 a 假且 b 假，与 a 真矛盾。
- 若 a 假（甲说谎）：则 b 真、c 假。检验：甲说"乙在说谎"为假 ⇔ 乙说真话 ✓；
  乙说"丙在说谎"为真 ⇔ 丙说谎 ✓；丙说"甲乙都在说谎"为假 ⇔ 甲、乙至少一人说真话，
  乙确实说真话 ✓。全部自洽。

唯一自洽解：甲说谎、乙说真话、丙说谎，说真话的是乙。
